앱 설치하기

앱스토어에서 받지 않아도 돼요. 쓰는 브라우저에서 홈 화면에 추가하면 아이콘을 눌러 앱처럼 열려요.

옆으로 넘기거나 아래 다음 ›을 눌러도 돼요.

설치가 잘 안 되면

💬 카톡에서 링크를 열었다면카톡 안의 화면에서는 설치가 안 돼요. 오른쪽 위 메뉴에서 다른 브라우저로 열기를 누른 뒤 따라 해 주세요.
🔁 설치 메뉴가 안 보여요이미 설치돼 있으면 메뉴가 안 나와요. 홈 화면이나 앱스 화면에서 아이콘을 찾아보세요.
🌐 브라우저마다 메뉴가 달라요위에서 내가 쓰는 브라우저 탭을 골라 따라 해 주세요. 아이폰은 꼭 사파리에서 해야 해요.
🛡️ "안전하지 않은 앱" 경고가 떠요갤럭시에서 플레이 스토어를 거치지 않은 앱이라 뜨는 안내예요. 세부정보 더보기 → 무시하고 설치하기를 누르면 돼요.

설치했으면 이름과 숫자 4자리로 로그인하면 끝! 궁금한 건 운영진에게 물어봐 주세요 🙌
