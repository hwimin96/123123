# 풋살 클럽 앱 (PWA)

참석 투표 · 일정 관리 · 팀 편성 · 경기 타이머를 한 번에 쓰는 클럽용 웹앱이에요.
프론트엔드는 정적 파일(GitHub Pages), 데이터는 구글 시트 + Apps Script에 저장돼서 **서버 비용이 0원**이에요.

## 구조

```
futsal-app/
├─ index.html / style.css / app.js   앱 본체
├─ config.js                         ← API_URL, 클럽 이름 설정 (여기만 수정)
├─ manifest.webmanifest / sw.js      PWA (홈 화면 설치, 오프라인 폴백)
├─ install.html                      멤버용 설치 안내 페이지
├─ icons/                            앱 아이콘
└─ apps-script/Code.gs               구글 시트 백엔드
```

## 1) 백엔드 만들기 (구글 시트)

1. 새 구글 스프레드시트를 만들어요.
2. 메뉴 **확장 프로그램 → Apps Script** 를 열고, `apps-script/Code.gs` 내용을 통째로 붙여넣어요.
3. 왼쪽 **프로젝트 설정(⚙️)** 에서 시간대를 `Asia/Seoul` 로 바꿔요.
4. 함수 선택 칸에서 **`setup`** 을 골라 ▶ 실행해요. (권한 승인 필요)
   - `Members / Events / Votes / Teams` 시트가 만들어지고, 운영진 계정 **이름 `관리자` / PIN `0000`** 이 생겨요.
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 **웹 앱 URL** 을 복사해요. (`https://script.google.com/macros/s/.../exec`)

> Code.gs를 수정하면 **배포 관리 → 편집 → 새 버전** 으로 다시 배포해야 반영돼요.

## 2) 프론트엔드 연결

`config.js` 를 열어 수정해요.

```js
window.WD_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/.../exec',
  CLUB_NAME: '우리 풋살 클럽'
};
```

앱 이름/아이콘을 바꾸려면 `manifest.webmanifest`, `index.html`의 `<title>`, `icons/` 를 수정해요.

## 3) GitHub Pages로 올리기

1. GitHub에 새 저장소를 만들고 `apps-script/` 를 제외한 파일을 올려요.
2. **Settings → Pages → Branch: main / (root)** 로 켜요.
3. `https://<계정>.github.io/<저장소>/` 로 접속돼요. 이 주소를 멤버들에게 공유하고, 설치 방법은 `install.html` 로 안내해요.

## 4) 처음 쓸 때

1. `관리자 / 0000` 으로 로그인 → **내 정보**에서 PIN부터 바꿔요.
2. **내 정보 → 멤버 관리**에서 멤버(이름 + PIN 4자리)를 추가해요. 다른 운영진은 권한을 `운영진`으로 지정해요.
3. **일정** 탭에서 `＋ 일정 추가`.

## 기능

| 탭 | 설명 |
|---|---|
| 일정 | 일정 목록, 참석/미정/불참 투표, 명단 보기. 운영진은 일정 추가·삭제 |
| 팀 편성 | 참석 확정자를 2~4팀으로 랜덤 배정, 이름을 눌러 팀 이동, 운영진이 저장하면 모두에게 공개 |
| 타이머 | 5/7/10/12/15분, 종료 시 소리·진동, 화면 꺼짐 방지, 팀별 점수 |
| 내 정보 | PIN 변경, 설치 안내, 운영진 멤버 관리 |

## 알아둘 점

- PIN 4자리는 **친구들끼리 쓰는 모임용 수준**의 보안이에요. 로그인 10회 실패 시 10분간 잠기지만, 민감한 정보는 넣지 마세요.
- 시트에 직접 들어가서 멤버·일정을 고쳐도 돼요. 날짜는 `2026-11-05`, 시간은 `20:00` 형식(텍스트)으로 적어요.
- Apps Script 무료 한도(일일 실행 시간 등)가 있지만, 수십 명 규모 클럽에는 충분해요.
- 타이머 소리는 iOS 정책상 **시작 버튼을 누른 뒤**에만 울려요. 무음 모드에서는 진동/화면 표시로 알려줘요.
